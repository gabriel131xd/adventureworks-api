# adventureworks-api
Codigos-API
🧩 Projeto: adventureworks-api
Este projeto foi desenvolvido para o Hackathon da empresa Santodigital com foco em construir uma API RESTful em Node.js que se conecta ao banco de dados AdventureWorks.

📁 Estrutura do Projeto
config/ – Arquivos de configuração (ex: banco, autenticação).
middleware/ – Middlewares para autenticação, logging etc.
models/ – Definições das entidades e interação com o banco de dados.
routes/ – Rotas da API organizadas por domínio.
tests/ – Testes automatizados.
app.js – Arquivo principal de inicialização da aplicação.
db.js – Configuração da conexão com o banco.
index.js – Ponto de entrada do servidor.
